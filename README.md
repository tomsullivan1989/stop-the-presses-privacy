# Stop the Presses - Privacy Policy

This repository hosts the public privacy policy for **Stop the Presses**, a
word game for Android.

The policy itself is in [`index.md`](index.md) and is served via GitHub Pages
at:

**https://tomsullivan1989.github.io/stop-the-presses-privacy/**

That URL is what goes in the Google Play Console's "Privacy policy" field and
in the AdMob app settings.

To update the policy, edit `index.md` and push - GitHub Pages will re-publish
within a minute or two.
